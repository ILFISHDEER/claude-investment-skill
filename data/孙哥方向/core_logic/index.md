## 分析生成指令

当你需要为某只股票生成深度分析时，对AI说：

```
基于以下信息，生成深度核心逻辑分析，必须包含全部10个维度：

股票：[公司名] ([代码])
行业：[所属行业]
一句话：[一句话描述]

要求：
1. 每个维度写3-5段，有数据支撑
2. 护城河分析用表格呈现
3. 风险矩阵评估概率和影响
4. 估值逻辑要有数字和区间
5. 最后给出明确的买入/持有/观望评级
6. 标记是否为科创板（如适用）

输出到文件：data/孙哥方向/core_logic/[方向].md
```

## 与tickers.yaml的关系

```
tickers.yaml                    core_logic/*.md
    │                              │
    ├── 基础信息（代码、市场）      ├── 深度分析（10维度）
    ├── 状态（上市/未上市）        ├── 竞争格局详解
    ├── 一句话描述                 ├── 风险矩阵
    └── core_logic字段 ─────────→  指向详细分析的索引
         （简要说明）              （深度分析文档）
```

**tickers.yaml** 用于快速查询和程序读取  
**core_logic/*.md** 用于人工深度研究和报告引用
