# 风格动态控制使用指南

## 功能概述

风格参数现在可以**动态控制**生成内容的写作风格。系统会：
1. 从 `config.yaml` 读取 `output.style` 配置
2. 自动加载对应的风格指南文件
3. 将风格要求注入到每个 Agent 的执行指令中
4. 验证风格与深度的匹配度

## 配置示例

在 `themes/{主题}/config.yaml` 中配置：

```yaml
output:
  depth: "L2"           # L0/L1/L2/L3/L4
  style: "社交媒体风"    # 11种风格可选
  market_focus: "中美双线"
```

## 11种可用风格

| 风格名称 | 最佳深度 | 特点 |
|----------|----------|------|
| **一句话风** | L0 | 极简结论 |
| **社交媒体风** | L0-L1 | emoji丰富、易转发 |
| **新闻快讯风** | L0-L2 | 客观、5W1H |
| **内部备忘录风** | L1-L2 | 结论先行、带TODO |
| **专业投行风** | L1-L4 | 专业严谨、逻辑清晰 |
| **散户科普风** | L1-L3 | 口语化、易懂 |
| **FAQ问答风** | L0-L4 | 由浅入深 |
| **故事叙事风** | L1-L4 | 情节驱动 |
| **对比分析风** | L1-L4 | 并排对比表 |
| **学术论文风** | L3-L4 | 完整方法论 |
| **投资手册风** | L4 | 百科全书式 |

## 使用方式

### 方式1：生成报告指令（带风格要求）

```bash
python generate_report_v2.py --theme 物理AI --instructions
```

输出会包含：
- 风格适配检查（验证风格与深度是否匹配）
- 写作风格要求（语气、句式、结构）
- 深度特定要求（字数、格式）
- 禁用事项和必用结构

### 方式2：多 Agent 执行（自动注入风格）

```bash
python multi_agent_orchestrator.py --theme 物理AI
```

每个 Agent 的指令会自动包含：
```markdown
## 写作风格要求（必须遵守）

**风格名称**: 社交媒体风
**风格定位**: 社交传播、emoji丰富

### 语气要求
- 轻松活泼，带表情符号
- 口语化表达
- 制造话题性

### 句式要求
- 平均句长：15-20字
- 多用短句和断句
- 每句可加emoji

### 深度特定要求
- 使用emoji表情
- 300-500字
- 短句为主
- 易转发

### 禁用事项（必须遵守）
- 长段落无emoji
- 专业术语无解释
- 无话题标签
...
```

## 风格映射

配置值支持多种写法，自动映射到文件：

```python
"专业投研风" -> "专业投行风.md"
"投研风" -> "专业投行风.md"
"社交媒体风" -> "社交媒体风.md"
"社媒风" -> "社交媒体风.md"
"微博风" -> "社交媒体风.md"
```

## 风格验证

系统会自动验证风格与深度的匹配度：

```
## 风格适配检查

**风格**: 社交媒体风
**深度**: L4
**状态**: ⚠️ 风格'社交媒体风'用于L4深度效果可能不佳
```

如果风格与深度不匹配，会给出警告并推荐适合的风格。

## 快速切换风格示例

修改 `config.yaml` 中的 `output.style`，然后重新生成：

```bash
# 专业投研风格
output:
  style: "专业投研风"
  depth: "L3"

# 社交媒体风格
output:
  style: "社交媒体风"
  depth: "L1"

# 学术论文风格
output:
  style: "学术论文风"
  depth: "L4"
```

## 代码调用

### 直接使用风格管理器

```python
from style_manager import StyleManager

sm = StyleManager()

# 获取风格指令
instructions = sm.get_agent_style_instructions("社交媒体风", depth="L2")

# 验证风格与深度
ok, msg = sm.validate_style_depth("学术论文风", "L4")
# 返回: (True, "✅ 风格'学术论文风'非常适合L4深度")

# 列出所有风格
styles = sm.list_available_styles()
```

### 在 Agent 中使用

```python
from multi_agent_orchestrator import MultiAgentOrchestrator

orchestrator = MultiAgentOrchestrator(theme="物理AI")
orchestrator.load_config()

# Agent 指令会自动包含风格要求
instructions = orchestrator._generate_agent_instructions(
    agent_name="市场情绪Agent",
    system_prompt=...,
    module_content=...,
    dependency_data=...
)
# 指令中包含 ## 写作风格要求（必须遵守）
```

## 新增风格

1. 在 `styles/` 目录创建新的风格文件（如 `我的风格.md`）
2. 按照风格模板编写：定位、篇幅匹配、语气特征、句式特征、结构特征
3. 在 `style_manager.py` 的 `STYLE_MAPPING` 中添加映射（可选）
4. 在 `config.yaml` 中使用新风格名称

## 文件关系

```
config.yaml
    ↓ output.style = "社交媒体风"
    ↓
style_manager.py
    ↓ STYLE_MAPPING 映射到 "社交媒体风.md"
    ↓
styles/社交媒体风.md
    ↓ 提取语气、句式、结构、禁用、必用
    ↓
multi_agent_orchestrator.py
    ↓ 注入到 Agent 执行指令
    ↓
Agent 输出（符合指定风格）
```

## 注意事项

1. **风格必须存在**：配置的风格名称必须在 `styles/` 中有对应的文件
2. **深度匹配**：系统会警告风格与深度不匹配的情况
3. **Agent 遵守**：每个 Agent 的执行指令都包含强制性的风格要求
4. **一致性**：所有章节会保持统一的写作风格
