# Recurring Issues

## 数据覆盖不全

**现象**
- 15号模块AI Brain层最初只列7家公司
- 遗漏国产AI训练芯片（天数/燧原/壁仞）、机器人芯片（地平线/黑芝麻）
- 未区分训练/推理/边缘/机器人芯片

**影响**
- 投资决策信息不完整
- 遗漏重要标的（如地平线）
- 公司定位错误（瑞芯微被误放在AI Brain层）

**根因**
- 过度依赖tickers.yaml静态数据
- 缺乏主动补全机制
- AI芯片领域变化快，知识滞后

**对策**（已实施）
- [x] 重写15号模块，细分为5个子层
- [x] 补充20+家公司（美股/A股/港股/未上市）
- [x] CLAUDE.md新增"主动补全机制"
- [ ] 建立"AI芯片公司清单"动态维护

**验证**
- [ ] 下次涉及AI芯片时，检查是否主动询问补充

## 数据格式不一致

**现象**
- valuation.yaml 中 market_cap 有时用"亿"，有时用"B"
- 股价有时用人民币，有时用美元，无货币标识
- 日期格式不统一（YYYY-MM-DD vs YYYY/MM/DD）

**影响**
- 计算错误
- 报告生成失败
- 需要人工检查和修正

**对策**
- [ ] 统一数据格式标准
- [ ] 添加数据验证脚本
- [ ] 在 CLAUDE.md 中定义格式规范

---

## 模块依赖声明不完整

**现象**
- 删除一个模块后，另一个模块报错
- 模块 B 依赖模块 A 的内容，但 frontmatter 未声明
- 模块加载顺序错误

**影响**
- 系统维护困难
- 模块无法独立使用
- 删除模块风险高

**对策**
- [x] 已要求所有模块在 frontmatter 声明 dependencies
- [ ] 需要验证现有模块依赖是否完整
