# 对比分析风风格指南

## 定位
结构化对比、一目了然、选择导向

## 适用场景
标的选择、方案对比、优劣分析、决策支持

## 篇幅匹配
- **L0一句话**: ✅ 结论对比
- **L1一页纸**: ✅ 简单对比表
- **L2简报**: ✅ 完整对比（最适合）
- **L3深度**: ✅ 多维度对比
- **L4手册**: ✅ 全面对比手册

## 语气特征
- 中立、客观、不偏不倚
- 让事实和数据说话
- 给出明确选择建议

## 句式特征
- "A vs B"结构
- "优势/劣势"对比
- "适合/不适合"分类

## 结构特征
```
【核心结论】（一句话谁更适合）

【对比总览】（关键指标并排对比表）

【维度1对比】（估值/业绩/技术）
├─ A的优势
├─ B的优势
└─ 结论

【维度2对比】（护城河/风险/增长）
├─ A的优势
├─ B的优势
└─ 结论

...

【综合评分】（打分卡）

【选择建议】（不同场景的选择）
```

```
|------|-------|-------|--------|

| 毛利率 | XX% | YY% | 高者胜 |
| 护城河 | 宽/窄/无 | 宽/窄/无 | - |
| 催化剂 | 有/无 | 有/无 | - |
| 风险 | 高/中/低 | 高/中/低 | 低者胜 |
```

```
| 方案 | 方案A | 方案B | 方案C |
|------|-------|-------|-------|

| 适合人群 | 激进 | 稳健 | 保守 |
```

## 示例对比

**专业风**：
"英伟达PE 65x，高于AMD的40x，建议关注估值更合理的AMD。"

**对比分析风**（L2简报版）：
```
【英伟达 vs AMD：AI芯片双雄谁更值得买？】

【核心结论】
英伟达适合高风险偏好，AMD适合性价比投资者。

【对比总览】
| 指标 | 英伟达(NVDA) | AMD | 胜出方 |
|------|--------------|-----|--------|
| 股价 | $950 | $165 | - |
| PE(TTM) | 65x | 40x | AMD ✅ |
| PB | 42x | 8x | AMD ✅ |
| 毛利率 | 78% | 47% | NVDA ✅ |
| 收入增速 | +262% | +85% | NVDA ✅ |
| 市占率(AI芯片) | 90% | 8% | NVDA ✅ |
| 估值分位 | 95% | 75% | AMD ✅ |

【维度1：估值对比】
• 英伟达：PE 65x（历史95%分位），显著高估
• AMD：PE 40x（历史75%分位），合理偏高

→ 结论：AMD估值更合理

【维度2：增长对比】
• 英伟达：Q1收入+262%，Q2指引+240%，增速放缓
• AMD：Q1收入+85%，AI芯片业务翻倍增长

→ 结论：英伟达增速更高，但边际放缓

【维度3：护城河对比】
• 英伟达：CUDA生态垄断，软件护城河极深
• AMD：硬件性能追赶，软件生态薄弱

→ 结论：英伟达护城河更宽

【维度4：风险对比】
• 英伟达：估值泡沫、AI需求见顶、竞争加剧
• AMD：市场份额小、毛利率低、技术追赶风险

→ 结论：英伟达风险更高（估值风险）

【综合评分】（满分100）
| 维度 | 权重 | 英伟达 | AMD |
|------|------|--------|-----|
| 估值 | 25% | 60 | 75 |
| 增长 | 25% | 95 | 70 |
| 护城河 | 20% | 95 | 60 |
| 风险 | 20% | 50 | 65 |
| 催化剂 | 10% | 90 | 70 |
| 总分 | - | 78 | 68 |

【选择建议】

如果你是：
□ 激进型投资者 → 选英伟达（高成长但高风险）
□ 稳健型投资者 → 选AMD（性价比高）
□ 保守型投资者 → 都不选（等回调）

【仓位建议】
• 英伟达：卫星仓位5-10%
• AMD：卫星仓位8-12%
• 同时持有：不超过总仓位20%
```

## 对比技巧
1. **并排呈现**：左右或表格对比，一目了然
2. **量化打分**：避免主观，用数字说话
3. **权重分配**：不同维度重要性不同
4. **场景化建议**：不同人群不同选择
5. **综合评分**：最后给一个总体判断

## 禁用
- 只有描述没有对比
- 主观判断无数据支撑
- 维度太少（至少6个）
- 没有明确胜出方

## 必用结构
- 核心结论在开头
- 并排对比表格
- 多维度分析
- 综合评分表
- 场景化选择建议
