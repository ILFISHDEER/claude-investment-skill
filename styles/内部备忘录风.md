# 内部备忘录风风格指南

## 定位
快速决策、行动导向、信息密度高

## 适用场景
内部讨论、决策支持、行动指令、会议记录

## 篇幅匹配
- **L0一句话**: ✅ 适合（结论先行）
- **L1一页纸**: ✅ 最适合
- **L2简报**: ✅ 次适合
- **L3深度**: ⚠️ 可接受（Executive Summary形式）
- **L4手册**: ❌ 不推荐

## 语气特征
- 直接、高效、无废话
- 结论先行，理由在后
- 明确责任人/时间节点

## 句式特征
- 平均句长：10-15字
- 多用祈使句、命令句
- Bullet points为主

## 结构特征
```
TO: [收件人]
FROM: [发件人]
DATE: [日期]
RE: [主题]

【结论】（一句话核心建议）

【背景】（为什么要关注，2-3句）

【关键信息】
• 事实1
• 事实2
• 事实3

【风险/问题】
• 风险1
• 风险2

【行动建议】
□ 行动1（负责人：XXX，时间：X月X日）
□ 行动2（负责人：XXX，时间：X月X日）

【需要决策】
Q1: [问题1] → 选项A/B
Q2: [问题2] → 选项A/B

【附件/参考】
• [文件名]
• [数据链接]
```

## 篇幅标准
| 深度 | 字数 | 阅读时间 | 适用场景 |
|------|------|----------|----------|
| L0 | 20-50字 | 10秒 | 即时通知 |
| L1 | 300-500字 | 1-2分钟 | 快速决策 |
| L2 | 800-1200字 | 5分钟 | 完整简报 |

## 示例对比

**专业风**：
"英伟达当前PE 65x，处于历史95%分位，建议关注回调至30x以下的配置窗口。"

**内部备忘录风**：
```
TO: 投资委员会
FROM: 研究部
DATE: 2026-05-24
RE: 英伟达持仓建议

【结论】
建议减仓英伟达至5%以下，等待回调至30x PE再补仓。

【背景】
英伟达PE升至65x（历史95%分位），估值已充分反映AI乐观预期。Q2指引虽超预期，但增速放缓信号明显。

【关键数据】
• 当前PE：65x（历史平均35x）
• Q1营收：260亿美元（同比+262%）
• Q2指引：280亿美元（同比+240%，增速↓）
• 机构目标价中位数：950美元（当前已接近）

【风险】
• AI Capex周期可能2027年见顶
• 竞争对手（AMD/自研芯片）份额提升
• 中国市场不确定性

【行动】
□ 减仓英伟达至5%（执行：交易部，截止：本周五）
□ 设置30x PE买入提醒（执行：研究部，截止：本周三）
□ 监控AMD竞争动态（执行：研究部，持续）

【待决策】
Q1: 是否完全清仓？→ A) 减仓至5% B) 清仓
Q2: 补仓价位？→ A) 30x PE B) 25x PE

【附件】
• 英伟达估值模型.xlsx
• 同业对比表.pdf
```

## 禁用
- 冗长背景介绍
- 无结论的纯分析
- 模糊的行动建议
- 没有责任人和时间

## 必用结构
- 结论在开头
- Bullet points为主
- 行动项带checkbox
- 明确责任人和DDL
