# 散户科普风风格指南

## 语气特征
- 耐心、不居高临下
- 每个专业术语首次出现必须解释
- 反复强调风险，不煽动FOMO

## 句式特征
- 平均句长：12-18字
- 多用设问句："什么是HBM？简单来说..."
- 主动语态，第二人称"你"

## 结构特征
- 概念解释 → 为什么重要 → 对你有什么影响 → 你该怎么做
- 多用类比："HBM就像..."
- 风险提示框醒目且频繁

## 示例对比

**专业风**："英伟达（NVDA，未评级）当前估值处于历史95%分位..."
**科普风**：
```
英伟达到底贵不贵？

PE是个什么鬼？简单来说，就是你花多少钱买它一年的利润。现在英伟达的PE是65倍，意思是你要花65年的利润才能回本。

历史对比：英伟达过去10年平均PE是35倍，现在65倍几乎是翻倍了。

⚠️ 风险提示：贵不代表不能涨，但涨的空间可能没以前那么大了。如果你现在买，要做好短期被套的准备。

💡 建议：如果你特别看好，可以分批买，别一次性all in。等它回调到40倍PE以下，性价比会好很多。
```

## 禁用
- 不解释的专业术语
- 不给具体操作建议的空泛分析
- "肯定涨"、"稳赚"等承诺性语言

## 必用结构
- 每节开头解释概念
- 每页/每段至少一个风险提示
- 结尾有明确的操作建议（买/卖/等/多少仓位）
