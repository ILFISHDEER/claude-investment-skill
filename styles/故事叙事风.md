# 故事叙事风风格指南

## 定位
引人入胜、情节驱动、情感共鸣

## 适用场景
投资故事、案例复盘、人物特写、趋势叙事

## 篇幅匹配
- **L0一句话**: ✅ 金句形式
- **L1一页纸**: ✅ 微型故事
- **L2简报**: ✅ 短故事（最适合）
- **L3深度**: ✅ 中篇故事
- **L4手册**: ✅ 长篇叙事

## 语气特征
- 叙事性强，有人物、时间、地点
- 情节起伏，有冲突和转折
- 让读者产生代入感

## 句式特征
- 平均句长：变化丰富（短句+长句交替）
- 多用对话、场景描写
- 时间线清晰

## 结构特征
```
【开头】钩子（场景/人物/冲突）

【背景】设定舞台（时间、地点、人物）

【冲突】核心问题/挑战

【发展】过程、转折、高潮

【结局】结果如何

【启示】对投资者的启发
```

```

理由很充分：估值太高、竞争加剧...

但随后...

这个案例教会我们...
```

## 篇幅标准
| 深度 | 字数 | 结构 | 适用场景 |
|------|------|------|----------|
| L0 | 15-30字 | 金句 | 传播用 |
| L1 | 300-500字 | 微型故事 | 快读 |
| L2 | 1000-2000字 | 完整短篇 | 深度快读 |
| L3 | 3000-5000字 | 中篇 | 案例复盘 |
| L4 | 8000字+ | 长篇 | 完整传记/复盘 |

## 示例对比

**专业风**：
"英伟达PE 65x，估值处于历史高位，建议谨慎。"

**故事叙事风**（L2简报版）：
```
【那个错过英伟达的人】

2024年初，张磊（化名）坐在电脑前，看着英伟达的K线图。

"PE 40倍，太贵了。"他在雪球上写下这句话，"等回调到30倍再买。"

当时股价是400美元。

他没有买。

三个月后，股价涨到了600美元。PE变成了50倍。

"更贵了，更不能买。"他安慰自己。

又过了三个月，股价900美元。PE 65倍。

他终于明白：在产业爆发期，估值锚会漂移。

这个故事告诉我们：

当产业趋势确认时，不要用静态估值锚定动态增长。贵，不一定是卖出的理由；便宜，也不一定是买入的信号。

【启示】
• 产业爆发期，估值容忍度要放宽
• 用PEG而非PE衡量 growth stock
• 宁可贵买龙头股，不便宜买落后股
```

## 叙事技巧
1. **具体化**：用具体的人、时间、数字
2. **冲突感**：内心的犹豫、外部的质疑
3. **转折**：出人意料的发展
4. **金句**：结尾有让人记住的话
5. **启发**：让读者有收获

## 禁用
- 纯数据堆砌（没有情节）
- 没有人物（全是公司名）
- 没有情感起伏
- 平铺直叙（没有转折）

## 必用结构
- 有人物（真实或化名）
- 有时间线
- 有冲突（内心的或外部的）
- 有结局
- 有启示
