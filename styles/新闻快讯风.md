# 新闻快讯风风格指南

## 定位
客观报道、事实优先、倒金字塔结构

## 适用场景
盘前快讯、突发新闻、市场动态、投资简报

## 篇幅匹配
- **L0一句话**: ✅ 最适合
- **L1一页纸**: ✅ 次适合
- **L2简报**: ✅ 适合
- **L3深度**: ⚠️ 可接受（需拆分多篇）
- **L4手册**: ❌ 不推荐

## 语气特征
- 客观、中立、无情绪
- 事实驱动，观点分离
- 快速传递核心信息

## 句式特征
- 平均句长：15-20字
- 倒金字塔：最重要信息在前
- 5W1H要素完整

## 结构特征
```
【标题】：谁+做了什么+结果（30字以内）

【导语】：一句话概括核心事实

【正文】：
• 发生了什么（What）
• 什么时候（When）
• 涉及谁（Who）
• 在哪里（Where）
• 为什么（Why）
• 影响如何（How）

【市场反应】：股价/板块/相关标的表现

【背景】：补充必要的背景信息

【风险提示】：信息来源/不确定性说明
```

## 篇幅标准
| 深度 | 字数 | 结构 | 阅读时间 |
|------|------|------|----------|
| L0 | 15-30字 | 标题 | 3秒 |
| L1 | 200-300字 | 导语+3段 | 1分钟 |
| L2 | 500-800字 | 5W1H完整 | 3分钟 |

## 示例对比

**专业风**：
"英伟达FY2026Q1营收260亿美元，同比增262%，毛利率78%，数据中心业务占87%。"

**新闻快讯风**：
```
【英伟达Q1业绩超预期，数据中心收入同比增427%】

北京时间5月23日，英伟达发布FY2026Q1财报，营收260亿美元（预期247亿），EPS 5.98美元（预期5.58美元）。

【关键数据】
• 营收：260亿美元，同比+262%
• 毛利率：78.4%，环比+2.4pct
• 数据中心：226亿美元，同比+427%
• 游戏业务：26亿美元，同比-8%

【市场反应】
盘后股价一度涨超7%，现报950美元。

【重要指引】
Q2营收指引280亿美元（±2%），高于预期。

【风险提示】
本快讯基于公开财报，具体业务细节以官方披露为准。
```

## 禁用
- 主观判断（用"市场认为"替代"我认为"）
- 情绪化词汇
- 模糊时间（必须具体到日期）
- 未标注来源的数据

## 必用结构
- 标题包含核心事实
- 导语5W1H完整
- 关键数据用bullet points
- 明确标注信息来源
