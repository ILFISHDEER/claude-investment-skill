## 风格详细说明

### 传播类（轻量）

**一句话风**
- 定位：极简结论
- 长度：20-50字
- 场景：提醒、传播、金句
- 结构：核心结论一句话
- 示例："PE 65x历史高位，建议减仓至5%，等30x以下再补仓。"

**社交媒体风**
- 定位：社交传播
- 长度：15-500字
- 场景：朋友圈、微博、社群
- 结构：emoji + 短句 + 标签
- 特点：易读、易转发、带情绪

**新闻快讯风**
- 定位：客观报道
- 长度：300-2000字
- 场景：快讯、热点追踪
- 结构：5W1H、倒金字塔
- 特点：客观、时效、引用信源

### 决策类（效率）

**内部备忘录风**
- 定位：行动导向
- 长度：300-1200字
- 场景：内部讨论、决策支持
- 结构：TO/FROM/DATE/RE + 结论 + 行动项
- 特点：结论先行、带责任人DDL

**对比分析风**
- 定位：结构化对比
- 长度：1500-6000字
- 场景：标的选择、方案对比
- 结构：对比总览表 + 多维度对比 + 综合评分
- 特点：一目了然、选择导向

### 研究类（深度）

**专业简报风**
- 定位：专业分析
- 长度：800-8000字
- 场景：正式报告、客户交付
- 结构：投资要点 + 核心逻辑 + 估值 + 风险提示
- 特点：逻辑清晰、数据驱动

**深度研报风**
- 定位：深度研究
- 长度：3000-15000字
- 场景：卖方研报级别
- 结构：7大章节完整分析
- 特点：全面深入、行业对标

**学术论文风**
- 定位：严谨研究
- 长度：8000-20000+字
- 场景：学术发表、方法论创新
- 结构：摘要 + 引言 + 文献综述 + 方法 + 实证 + 讨论 + 结论
- 特点：假设-验证-结论、承认局限

**投资手册风**
- 定位：百科全书
- 长度：10000字+
- 场景：系统学习、知识库
- 结构：12+章节完整手册
- 特点：全面系统、可检索

### 教育类（易懂）

**FAQ问答风**
- 定位：知识普及
- 长度：500-6000字
- 场景：新手入门、常见问题
- 结构：Q&A由浅入深
- 特点：即查即用、降低门槛

**故事叙事风**
- 定位：案例教育
- 长度：500-8000+字
- 场景：投资故事、案例复盘
- 结构：开头→背景→冲突→发展→结局→启示
- 特点：情节驱动、情感共鸣

## 使用建议

1. **按场景选**：传播用社交媒体/一句话，决策用备忘录/对比分析，研究用深度研报/学术论文
2. **按时间选**：时间紧选L0-L1，时间充裕选L2-L4
3. **按受众选**：内部用备忘录，客户用专业简报，公众用新闻/社交媒体
4. **按目的选**：说服用故事，教育用FAQ，决策用对比分析
