# 路演PPT风风格指南

## 语气特征
- 简洁有力，每页一个核心信息
- 结论先行，数据支撑
- 适合口头演讲时配合阅读

## 句式特征
-  bullet points 为主
- 每点不超过一行
- 关键数字加粗

## 结构特征
- 每页 = 标题 + 3-5个 bullet + 1个图表/数据
- 总页数控制：L1=1页, L2=10页, L3=30页
- 过渡页清晰："第一部分：宏观"、"第二部分：产业链"

## 页面模板

```
【页面标题】：一句话结论

• 支撑点1：[数据]
• 支撑点2：[数据]
• 支撑点3：[数据]

[图表占位：Mermaid或表格]

Speaker Note: [演讲者备注，口头补充内容]
```

## 示例对比

**专业风**："英伟达（NVDA，未评级）当前估值处于历史95%分位，虽然GPU需求持续强劲，但需警惕AI资本开支周期见顶风险。建议关注PE回落至30x以下的配置窗口。"

**路演风**：
```
英伟达：短期高估，长期仍看好

• 当前PE 65x，处于历史95%分位 ⚠️
• 但GPU需求年增50%+，供不应求 ✅
• 风险：AI Capex周期可能在2027年见顶
• 策略：等回调至30x PE再重仓

[PE历史分位图]
```

## 禁用
- 超过两行的一句话
- 没有数据的观点
- 没有结论的页面
