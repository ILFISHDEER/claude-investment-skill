# FAQ问答风风格指南

## 定位
问题导向、即查即用、降低阅读门槛

## 适用场景
新手入门、常见问题、快速答疑、知识普及

## 篇幅匹配
- **L0一句话**: ✅ 适合（A部分）
- **L1一页纸**: ✅ 最适合
- **L2简报**: ✅ 次适合
- **L3深度**: ✅ 可接受（扩展Q&A）
- **L4手册**: ✅ 适合（完整FAQ库）

## 语气特征
- 对话感强，像回答问题
- 耐心，不假设读者背景
- 层层递进，从浅到深

## 句式特征
- Q: 简洁的问题（15字以内）
- A: 清晰的回答（50-100字）

## 结构特征
```
【核心问题】（一句话总结）

Q1: [最常见问题]？
A: [直接回答]

Q2: [进阶问题]？
A: [详细回答]

Q3: [深度问题]？
A: [完整解释]

...

【速查表】（关键数据汇总）

【相关阅读】（延伸阅读链接）
```

## FAQ设计原则

### 问题设计（从浅到深）
```
Level 1: 是什么？（概念）
Level 2: 为什么重要？（意义）
Level 3: 现在怎么样？（现状）
Level 4: 怎么看/怎么办？（判断/行动）
```

### 回答结构
```
A: [一句话直接回答]

[详细解释]

[举例/数据]

[注意事项]
```

## 篇幅标准
| 深度 | 问题数 | 字数/答案 | 总字数 |
|------|--------|-----------|--------|
| L0 | 1个 | 15-30字 | 15-30字 |
| L1 | 3-5个 | 50-100字 | 500-800字 |
| L2 | 8-12个 | 100-200字 | 1500-2500字 |
| L3 | 15-20个 | 200-300字 | 4000-6000字 |

## 示例对比

**专业风**：
"英伟达当前PE 65x，处于历史95%分位，建议关注回调至30x以下的配置窗口。"

**FAQ问答风**（L2简报版）：
```
【英伟达投资FAQ】

Q1: 英伟达到底是做什么的？
A: 做AI芯片的，简单说就是AI的"大脑"。

ChatGPT、自动驾驶、机器人背后都要用它的芯片。现在全球90%的AI训练都用它的芯片。

⚠️ 注意：它不直接做AI应用（比如不做ChatGPT），而是卖铲子给做AI的公司。

---

Q2: PE 65倍是什么意思？贵吗？
A: PE就是"市盈率"，65倍意思是你花65块钱买它1块钱的年度利润。

贵不贵要看跟谁比：
• 跟自己历史比：过去10年平均35倍，现在65倍确实贵
• 跟同行比：AMD 40倍，英特尔15倍，它是最贵的
• 跟增长比：如果利润每年翻倍，PEG=0.65，其实不贵

结论：绝对值贵，但相对增长来说还能接受。

---

Q3: 为什么它这么贵还在涨？
A: 三个原因：
1. 供不应求：AI芯片卖断货，交货要等6个月
2. 定价权强：垄断地位，可以涨价
3. 预期好：市场相信AI还会爆发

风险：如果AI需求见顶，估值会快速回落。

---

Q4: 现在还能买吗？
A: 看你的投资风格：

【激进型】→ 可以小仓位（5-10%），但要设止损
【稳健型】→ 等回调到40倍PE再考虑
【保守型】→ 别追高了，等下一个周期

【速查表】
| 指标 | 当前值 | 历史均值 | 判断 |
|------|--------|----------|------|
| PE | 65x | 35x | 偏高 |
| 毛利率 | 78% | 65% | 优秀 |
| 收入增速 | +262% | +50% | 爆发 |
```

## 禁用
- 问题太长（超过20字）
- 回答绕弯子（不直接回答）
- 纯数据没有解释
- 问题之间没有逻辑递进

## 必用结构
- 问题由浅入深
- 一句话直接回答开头
- 有具体例子
- 有速查表总结
- 相关阅读延伸
