## 层级一：AI Brain / 智能大脑

**产业链位置**：最顶层，软件定义硬件  
**核心壁垒**：算法、数据、生态  
**铲子属性**：⭐⭐⭐⭐⭐（收过路费模式）  
**⚠️ 注意**：本层级细分为多个子层，玩家众多，信息可能不完整，需持续补充

### 细分结构

```
AI Brain层
├── 1.1 云端训练芯片（Training）     [最大算力需求]
├── 1.2 云端推理芯片（Inference）     [规模化部署]
├── 1.3 边缘AI芯片（Edge）           [本地推理]
├── 1.4 端侧机器人芯片（Robot SoC）    [机器人专用]
└── 1.5 AI算法/软件平台               [框架层]
```

## 层级二：Compute / 算力层

**产业链位置**：AI Brain的底层支撑  
**核心壁垒**：制程、封装、生态  
**铲子属性**：⭐⭐⭐⭐⭐（所有AI都需要）  
**⚠️ 注意**：本层玩家众多，需区分GPU/ASIC/FPGA/DPU

### 细分结构

```
Compute层
├── 2.1 AI芯片制造（Foundry）      [最大瓶颈]

```
