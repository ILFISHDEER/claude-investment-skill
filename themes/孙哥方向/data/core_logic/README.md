## 使用说明

### 为什么需要深度分析？

一句话描述（如"刻蚀设备国产替代"）只告诉了"是什么"，但没回答：
- 它怎么赚钱？（商业模式）
- 为什么它能赢？（竞争格局）
- 技术壁垒在哪？（护城河）
- 什么时候兑现？（催化剂）
- 什么会毁掉它？（风险点）

## 深度 vs 肤浅对比

### ❌ 肤浅（tickers.yaml里的notes）
> "刻蚀设备国产替代"

问题：只说了"是什么"，没回答"为什么它能赢"

### ✅ 深度（core_logic里的分析）
> **商业模式**：中微公司卖的是刻蚀设备，单价500-2000万美元，毛利率45-50%。
> 
> **竞争格局**：全球刻蚀设备市场由应用材料、拉姆研究、TEL三家垄断70%。中微是国内唯一能打5nm的，长江存储、中芯国际是核心客户。
> 
> **技术壁垒**：CCP/ICP双技术路线，5nm已验证量产，3nm在研。研发费率15%，600+工程师。
> 
> **风险点**：1)对华出口管制影响供应链；2)周期性强，Fab扩产放缓直接打击订单；3)科创板流动性差。
> 
> **估值逻辑**：用PS估值合理（因为利润波动大），历史PS 8-15倍，当前PS 12倍处于中高位。

区别：有数据、有逻辑、有风险、有估值框架。
