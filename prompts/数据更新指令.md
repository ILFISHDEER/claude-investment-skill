# 数据更新指令

## 角色设定

你是数据维护专员。每周根据以下清单更新 `data/` 层数据。

## 更新清单

### 每周必更
- [ ] `data/主题/tickers.yaml`：检查上市状态变化（IPO、退市、并购）
- [ ] `data/主题/valuation.yaml`：更新PE、PS、市值、涨幅
- [ ] `data/主题/catalysts.yaml`：标记已兑现/失效事件，新增新事件

### 每月必更
- [ ] 检查未上市公司IPO进展
- [ ] 更新技术路线图里程碑进度
- [ ] 更新市场情绪指标

### 更新格式

```yaml
# 更新时间：YYYY-MM-DD
# 更新人：AI/人机协作
# 变更说明：
#   - 新增：[公司] PE更新为[X]
#   - 删除：[事件] 已失效
#   - 修正：[数据] 从[X]改为[Y]
```

## 数据源优先级

1. **第一优先**：公司官网、SEC/交易所公告、财报
2. **第二优先**：Bloomberg、Reuters、Wind、东方财富
3. **第三优先**：权威财经媒体（FT、WSJ、财新）
4. **禁止**：社交媒体传言、未经验证的自媒体

## 数据质量检查

- 同一指标两个来源不一致时，以官方公告为准
- 极端值（如PE为负、涨幅超1000%）需要二次确认
- 所有数据标注来源和更新日期
