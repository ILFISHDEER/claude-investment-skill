# ARK 颠覆性创新时间线框架

## 核心思想

- 颠覆性创新通常经历 **25年左右的周期**
- 早期（前5-10年）：技术验证期，波动大，大多数公司会失败
- 中期（10-20年）：商业化加速期，龙头开始显现
- 后期（20-25年）：成熟期，创新成为基础设施

## 技术周期阶段判断

| 阶段 | 特征 | 投资特征 | 代表案例 |
|------|------|---------|---------|
| 萌芽期 | 技术刚出现，无商业化 | 高风险高回报，适合VC | 2000年代的AI |
| 加速期 | 产品开始落地，收入快速增长 | 最佳投资窗口，波动大 | 2010年代的云计算 |
| 成熟期 | 成为基础设施，增速放缓 | 稳健收益，估值合理 | 2020年代的移动互联网 |
| 衰退期 | 被新技术替代 | 回避或做空 | 功能手机 |

## 判断标准

### 萌芽期 → 加速期的拐点信号
- [ ] 核心性能指标突破商业化门槛
- [ ] 成本曲线下降到可接受范围
- [ ] 出现第一个大规模商业应用
- [ ] 主流资本开始流入

### 加速期 → 成熟期的拐点信号
- [ ] 行业增速从50%+下降到20-30%
- [ ] 市场集中度提高，龙头市占率超过50%
- [ ] 利润开始释放，不再只是收入增长
- [ ] 成为其他行业的基础设施
