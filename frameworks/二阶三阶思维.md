# 二阶/三阶思维框架

## 核心概念

- **一阶思维**：直接结果。"这个公司做机器人，机器人很热，所以买它。"
- **二阶思维**：间接结果。"机器人很热 → 所有人都会做机器人 → 竞争加剧 → 真正赚钱的是卖铲子的（设备/芯片/材料）。"
- **三阶思维**：系统结果。"卖铲子的也被高估了 → 需要找卖铲子工具的（检测设备/工业软件/EDA）。"

## 应用步骤

1. **识别一阶热点**：当前市场最追捧的终端产品/应用是什么？
2. **推演二阶受益**：一阶热点的生产需要什么？（设备、材料、芯片、云服务）
3. **挖掘三阶机会**：二阶受益者的生产又需要什么？（检测设备、工业软件、关键零部件）
4. **评估四阶基建**：整个链条需要什么样的基础设施？（晶圆厂、洁净室、电力、物流）

## 铲子股识别清单

| 特征 | 说明 | 例子 |
|------|------|------|
| 寡头格局 | 行业前几名市占率极高 | 光刻机、EDA |
| 技术壁垒 | 需要长期积累，难以弯道超车 | 特种材料、精密仪器 |
| 客户粘性 | 切换成本高，认证周期长 | 半导体设备、航空材料 |
| 资本密集 | 后来者难以通过烧钱进入 | 晶圆厂、火箭发射 |
| 规模效应 | 越大越便宜，赢者通吃 | 云计算、存储 |

## 常见误区

- **误区1**：把二阶当三阶。实际上很多"铲子股"已经被市场充分认知（如英伟达），需要继续向下挖。
- **误区2**：忽视四阶基建。没有基础设施，前面三阶都是空中楼阁。
