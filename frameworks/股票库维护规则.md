## 维护周期

| 频率 | 动作 | 触发条件 |
|------|------|----------|
| **每周** | 数据更新 | 价格、市值、PE等财务数据自动抓取 |
| **每月** | 健康检查 | 评分低于阈值的标的红灯预警 |
| **每季** | 正式审议 | 基于季度财报和回测结果，执行剔除/纳入 |
| **随时** | 事件驱动 | IPO、并购、技术突破、丑闻等重大事件 |

## 评分体系（100分制）

每只股票从6个维度评分，总分=∑(维度分×权重)

| 维度 | 权重 | 评分标准 | 数据来源 |
|------|------|----------|----------|
| **价格表现** | 20% | 近1年涨幅 vs 行业平均 | Yahoo Finance |
| **估值健康** | 20% | PE/PB/PS 分位点 | Yahoo Finance |
| **财务质量** | 20% | 营收增速、毛利率、现金流 | 财报 |
| **技术地位** | 20% | 市场份额、专利数、技术路线先进性 | 研报 |
| **催化剂** | 10% | 未来3个月是否有明确催化剂 | 新闻监测 |
| **风险状况** | 10% | 诉讼、监管、债务等负面事件 | 舆情监测 |

### 评分等级

| 总分 | 等级 | 动作 |
|------|------|------|
| 90-100 | A+ | 核心仓位，重点跟踪 |
| 80-89 | A | 标准持仓，季度检视 |
| 70-79 | B | 观察名单，需要改进 |
| 60-69 | C | **黄色预警**，连续两季剔除 |
| <60 | D | **红色预警**，下季强制剔除 |

## 剔除规则（卖出信号）

### 强制剔除（立即执行）

| 条件 | 示例 |
|------|------|
| 退市/破产 | 股价<1美元超过30天 |
| 财务造假 | SEC/证监会调查确认 |
| 技术路线被证伪 | 量子计算公司被证明是骗局 |
| 核心产品失败 | 药物三期临床失败 |
| 并购私有化 | SpaceX如果上市后再私有化 |
| 行业逻辑崩塌 | 储能技术被颠覆 |

### 季度审议剔除

满足以下任一条件，进入剔除候选：

1. **连续两季度评分 <70分**
2. **跑输基准超过30%**（1年内相对收益）
3. **营收连续两季负增长**（成长股）
4. **估值泡沫破裂**（PE从>100倍跌至<20倍且趋势向下）
5. **市场份额持续流失**（连续两季下降>5%）

### 观察名单机制

- 评分60-69分的股票进入`watchlist.yaml`
- 给予一个季度改进期
- 下季评分仍<70则强制剔除

## 纳入规则（买入信号）

### IPO新股纳入

| 条件 | 要求 |
|------|------|
| 行业匹配 | 属于7大方向之一 |
| 市值门槛 | 美股>10亿美元，A股>100亿人民币 |
| 营收门槛 | 年收入>1亿美元（或增速>100%）|
| 技术稀缺性 | 填补产业链空白（如唯一国产替代）|

**流程**：
1. IPO公告后进入`候选池`
2. 上市后观察1个月（避免新股炒作）
3. 发布首份研报后正式纳入

### 已有股票重新发现

满足以下任一条件：

1. **技术突破**（如英伟达发布新架构）
2. **订单爆发**（如无人机公司拿到军方大单）
3. **估值修复**（股价腰斩但基本面未变）
4. **政策催化**（如核能获得政府明确支持）
5. **季度评分跃升**（从<60分跳至>80分）

### 铲子公司优先纳入

铲子股（设备/材料/零部件）比终端产品更容易长期持有：
- 行业出清后幸存者独享份额提升
- 无论终端谁赢，设备都卖
- 技术迭代周期更长

## 变更记录格式

每次剔除/纳入需在`changelog.yaml`记录：

```yaml
changes:
  - date: "2026-06-15"
    action: "剔除"
    direction: "storage"
    ticker: "SNDK"
    name: "闪迪"
    reason: "估值泡沫，PE从150倍跌至20倍，技术路线面临HBM替代"
    score_before: 85
    score_after: 55
    replaced_by: "N/A"
    
  - date: "2026-06-15"
    action: "纳入"
    direction: "quantum"
    ticker: "FORM"
    name: "FormFactor"
    reason: "量子测试设备铲子股，IonQ/Rigetti订单放量"
    initial_score: 78
    source: "IPO观察池转正"
```

## 自动化流程

### 脚本调用

```bash
# 完整维护流程
python maintenance.py --review quarterly

# 仅健康检查（生成预警报告）
python maintenance.py --review monthly

# 单个方向深度评估
python maintenance.py --direction quantum --review quarterly
```

### 输出文件

| 文件 | 内容 |
|------|------|
| `reports/健康检查-2026-05.md` | 月度评分报告，红黄牌预警 |
| `reports/季度审议-2026-Q2.md` | 剔除/纳入建议清单 |
| `changelog.yaml` | 变更历史记录 |
| `watchlist.yaml` | 观察名单（60-69分）|
| `candidates.yaml` | 候选池（待上市/待评估）|

## 人工复核点

即使自动化，以下情况仍需人工判断：

1. **技术路线争议**（如量子计算离子阱 vs 超导之争）
2. **地缘政治风险**（如某中国公司被列入实体清单）
3. **重大战略调整**（如特斯拉砍掉机器人项目）
4. **估值极端情况**（如股价1年涨50倍是否卖出）

**原则**：
- 机器负责"数据异常"预警
- 人负责"逻辑验证"决策
- 分歧时，铲子股优先保留，概念股优先剔除
